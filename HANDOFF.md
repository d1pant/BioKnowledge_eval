## What this repo is

Two Inspect tasks on *Aequorea victoria* GFP.

`gfp_barrel_orientation` — 107 samples, one β-strand residue each, no tools. Headline is `robust_accuracy` on the 98 residues with `|chromophore cosine| ≥ 0.2` (50 TOWARD, 48 AWAY). Ground truth is 1EMA chromophore geometry, mapped from CSV `inward`/`outward` to `TOWARD`/`AWAY`. Task arg: `-T subset=all` (default) or `-T subset=robust`.

`gfp_tolerant_site` — 5 brackets. The agent names three consecutive positions that each tolerated a single substitution. One tool, `residue_orientation(position)`, hard cap 5 successful calls. Headline is mean `accuracy`. Mean chance is 43.7%.

`confidence` in the JSON is one optional number from 0.5 to 1.0. Missing or invalid confidence does not change correctness. Do not ask for an interval.

Model-facing text must not name the paper, PDB 1EMA, S65T, UniProt, F64L, or chromophore residues 65–67. Those facts belong in the README and the transcripts. The only measured consecutive triple mutant is `Q157L:K158R:N159T` (bright, one barcode). Say that in the README only.

## Locked implementation details

- Task 1 solver is `system_message(SYSTEM_PROMPT)` plus `generate()`. User prompt is pre-rendered into `Sample.input` with JSON braces doubled. Do not use `prompt_template()` or `user_message()` for it. System prompt has no braces.
- Task 2 solver is `react(prompt=AgentPrompt(instructions=SYSTEM_PROMPT, handoff_prompt=None, assistant_prompt=None, submit_prompt=None), tools=[residue_orientation()], submit=False)`. Passing a string to `AgentPrompt` keeps Inspect's default assistant prompt and changes the locked system text.
- `HeadlineMetric` must be an object (`HeadlineMetric(metric="robust_accuracy")` or `metric="accuracy"`), not a bare string.
- Absolute imports only. Relative imports fail under `inspect eval path/task.py@name`.
- Task 1 `GenerateConfig(max_tokens=256)`. Task 2 `max_tokens=512`, `message_limit=24`.
- Call 6 of `residue_orientation` returns exactly: `residue_orientation is limited to 5 calls. No orientation is available.` Invalid positions do not increment the counter and do not reveal a label.
- `Score.as_float()` does not map `"C"` / `"I"` to 1 / 0. Unit tests of reduced metrics must pass numeric epoch means.
